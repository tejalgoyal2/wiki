This is a learning wiki. It began as a daily study habit, and it is public because what is learned is worth sharing.

## How it is made

- **Every day:** one lesson, one coding puzzle, new notes for the terms the lesson uses, and one older note made deeper.
- **Written with Claude**, from primary sources: the RFCs, the HTML and ECMAScript standards, Python's PEPs, official docs and papers. Each note lists its sources.
- **Checked by scripts:** every link must lead somewhere, and every code block marked as runnable is run before the site is published.
- **Read as it is studied**, and corrected when something turns out wrong.

## What it may get wrong

Mistakes are possible, especially in fast-moving topics. If you find one, open an issue on
[GitHub](https://github.com/tejalgoyal2/wiki). The sources on each page are the authority, not this wiki.
